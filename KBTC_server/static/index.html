Binance Demo API 키 만드는 법

  1. demo.binance.com 에 접속해 바이낸스 계정으로 로그인해요. 위에 DEMO TRADING 표시가 보이면 맞아요.
  2. 오른쪽 위 사람 아이콘을 누르고 Demo Trading API 를 선택해요.
  3. Create API (노란 버튼)를 눌러요.
  4. System generated 를 선택하고 Next.
  5. 이름을 적고 (예: KBTC) Next.
  6. API Key 옆 Copy → KBTC 의 API Key 칸에 붙여넣기.
  7. Secret Key 옆 Copy → KBTC 의 Secret Key 칸에 붙여넣기.
    Secret 은 이 화면을 벗어나면 다시 볼 수 없어요. 놓쳤다면 Delete 후 새로 만들면 돼요.
  8. 아래 API restrictions 에서 Enable Futures 가 체크돼 있는지 확인해요.
  9. KBTC 에서 연결하기 → 퀀트 트레이딩 시작 을 누르면 끝! 매일 09:00 일봉 마감 직후 자동으로 판단해요.
• 실계좌가 아닌 Demo 키만 써요. 진짜 돈은 움직이지 않아요.
• 선물 포지션 모드는 기본값인 단방향(One-way) 이어야 해요.
• API Key·Secret 은 비밀번호처럼 다른 사람에게 보내지 마세요.
바이낸스 Demo API 관리 열기 ↗
  1. okx.com 에 로그인하고 위쪽 메뉴에서 거래 → 모의 거래(Demo trading) 로 들어가요.
  2. 모의 거래 화면에서 오른쪽 위 사람 아이콘 → 모의 거래 API(Demo Trading API) 를 눌러요.
  3. API 키 만들기 → 이름(예: KBTC)을 적어요.
  4. Passphrase 를 직접 정해요. KBTC 에도 똑같이 넣어야 하니 꼭 기억하세요.
  5. 권한에서 읽기와 거래(Trade) 를 체크하고 확인해요.
  6. API Key · Secret Key 를 복사해 KBTC 칸에 붙여넣고, Passphrase 도 입력해요.
  7. 모의 거래 설정에서 계정 모드는 선물 모드(Spot and futures) 이상, 포지션 모드는 단방향(One-way) 으로 해 주세요.
  8. KBTC 에서 연결하기 → 퀀트 트레이딩 시작!
• 꼭 모의 거래 화면에서 만든 키여야 해요. 실거래 키는 연결되지 않아요.
• 마진은 교차(Cross)로 들어가요.
• Key·Secret·Passphrase 는 다른 사람에게 보내지 마세요.
OKX API 관리 열기 ↗
  1. testnet.gate.com 에 접속해 Gate 계정으로 로그인해요.
  2. 오른쪽 위 사람 아이콘 → API Keys 에서 Create API Key 를 눌러요.
  3. 이름(예: KBTC)을 적고, 권한에서 Perpetual Futures 의 읽기·쓰기(Read/Write) 를 체크해요.
  4. 만들어진 Key · Secret 을 복사해 KBTC 칸에 붙여넣어요. (Passphrase 는 필요 없어요)
  5. TestNet USDT 무기한 선물 계좌에 테스트 USDT 가 있는지 확인하고, 포지션 모드는 단일(Single) 로 두세요.
  6. KBTC 에서 연결하기 → 퀀트 트레이딩 시작!
• 실거래가 아닌 TestNet 키만 써요. 진짜 돈은 움직이지 않아요.
• 마진은 교차(Cross)로 들어가요.
• Key·Secret 은 다른 사람에게 보내지 마세요.
